## 1. Terminology Glossary

| Term | Operational Definition |
|---|---|
| **Prompt** | Natural language directive or structured set of instructions executed by a Large Language Model (LLM). |
| **Prompt Template** | Standardised, reusable prompt asset featuring static instructions and dynamic variable placeholders `{{...}}`. |
| **Variable** | Universal dynamic field substituted with user inputs upon runtime execution of a parameterized prompt. |
| **Workspace** | Governed collaborative container aggregating team prompts, categories, tags, and AI model credentials. |
| **Team** | Cluster of collaborators sharing an operational scope (department, functional unit, or cross-functional project). |
| **Organisation (Tenant)** | Top-level corporate entity supervising all subordinate teams, workspaces, users, and security baselines. |
| **Version** | Immutable historical snapshot of a prompt (content, metadata, inference parameters, and author attribution). |
| **Compare Versions Button** | Visual side-by-side diff tool highlighting additions, deletions, and textual edits across two revisions. |
| **Tag** | Cross-cutting keyword for rapid filtering (strictly limited to a maximum of 4 tags per prompt). |
| **Improve Assistant** | Built-in prompt engineering utility enhancing clarity, structure, and output formatting in one click. |
| **System API Keys** | Shared infrastructure credentials managed by platform administrators to power platform-native intelligence features (Improve feature and Prompt Lab: Architect & Improver). |
| **Organisation / Team API Keys** | Departmental inference credentials configured by managers in the Organisation menu, enabling collaborators to run and test prompts against approved AI models. |

## 2. Operational Onboarding Checklists

### Checklist for Team and Organisation Managers

| Onboarding Action | Status |
|---|:---:|
| Organisation and team settings confirmed in admin console | [ ] |
| Collaborators invited individually or via bulk roster import | [ ] |
| Functional teams established according to department | [ ] |
| Members mapped to their designated operational teams | [ ] |
| At least one workspace provisioned per team | [ ] |
| Role levels and permission boundaries configured | [ ] |
| AI model integrations (OpenAI, Anthropic, Google) tested and active | [ ] |
| Master category hierarchy established in the library | [ ] |
| Naming conventions and the 4-tag rule communicated to teams | [ ] |
| Welcome invitations and onboarding guidance distributed to users | [ ] |

---

### Checklist for Standard Users

| User First Steps | Status |
|---|:---:|
| User account verified via welcome activation email | [ ] |
| User profile completed (name, title, focus area) | [ ] |
| Workspace access confirmed for designated team | [ ] |
| First prompt drafted in Markdown with clear title and description | [ ] |
| Assigned up to 4 tags and appropriate category classification | [ ] |
| Prompt tested live or enhanced with the "Improve" assistant | [ ] |
| Initial version (v1.0) saved to the workspace repository | [ ] |
| Power Prompt browser extension installed and connected | [ ] |

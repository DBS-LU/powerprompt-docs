Le **Catalogue de modèles de prompts** met à votre disposition un réservoir exhaustif de prompts professionnels prêts à l'emploi. Conçus selon les meilleures pratiques d'ingénierie de prompt, ces modèles prêts à l'emploi accélèrent l'adoption de l'IA générative dans tous les métiers de l'entreprise.

---

## 1. Un vivier de 4 000 modèles de prompts d'entreprise

La plateforme Power Prompt intègre nativement un catalogue de **4 000 modèles de prompts**, avec une parité linguistique intégrale :
* **2 000 modèles de prompts en français**
* **2 000 modèles de prompts en anglais**

Ces modèles de prompts couvrent les cas d'usage majeurs des organisations :
* **Ressources Humaines :** Fiches de poste, grilles d'évaluation, plans de développement des compétences, communications internes.
* **Ventes & Négociation :** Qualification de prospects, préparation d'entretiens commerciaux, réponses aux objections, relances personnalisées.
* **Marketing & Communication :** Rédaction d'articles, briefs de campagne, lignes éditoriales, synthèses concurrentielles.
* **Service Client & Support :** Triage de tickets, qualification d'incidents, réponses types empathiques, résolutions guidées.
* **Finance, Gestion & Juridique :** Analyse de ratios financiers, détection de clauses contractuelles sensibles, notes de cadrage budgétaire.
* **Ingénierie & IT :** Revue de code sécurisé, documentation technique d'API, requêtes SQL, modélisation de processus métier.

---

## 2. Explorer et rechercher dans le catalogue

Pour consulter le vivier de modèles de prompts :
1. Dans le menu de navigation principal à gauche, cliquez sur **Modèles**.
2. Utilisez la barre de recherche textuelle pour cibler une thématique précise.
3. Filtrez par catégories métiers pour affiner votre exploration.
4. Cliquez sur la carte d'un modèle de prompt pour ouvrir sa fiche détaillée :
   * Consignes d'ingénierie intégrées.
   * Emplacements des variables dynamiques `{{...}}`.
   * Objectifs et résultats types attendus.

---

## 3. Instancier un modèle de prompt dans votre espace de travail

Les modèles de prompts du catalogue central constituent des structures de référence. Pour utiliser un modèle de prompt au quotidien et le personnaliser pour votre équipe :

1. Depuis la fiche détaillée du modèle de prompt, cliquez sur le bouton **Utiliser ce modèle**.
2. Sélectionnez l'**espace de travail** (Workspace) de destination ainsi que la **catégorie** de classement.
3. Power Prompt crée instantanément une copie autonome de ce prompt dans votre bibliothèque **Mes prompts**.
4. Vous pouvez ensuite adapter librement les instructions, renseigner vos variables, ajuster le ton ou publier différentes révisions sans altérer le modèle de prompt d'origine du catalogue.

---

## 4. Gouvernance et personnalisation : SaaS vs On-Premise

Le mode de gestion du catalogue de modèles dépend de votre type de déploiement :

* **Version SaaS publique :** Le catalogue de 4 000 modèles de prompts est un référentiel global supervisé et enrichi en continu par les équipes Power Prompt. Tous les utilisateurs peuvent consulter ces modèles et les importer dans leurs espaces de travail. La modification directe du catalogue central n'y est pas ouverte.
* **Déploiement On-Premise et Cloud privé :** Seuls les **Administrateurs de la plateforme** ont la possibilité de configurer, éditer, masquer ou enrichir le catalogue de modèles de prompts. Cela permet aux organisations déployant Power Prompt sur leur propre infrastructure d'intégrer leurs référentiels internes, chartes métiers et exigences de conformité spécifiques. Pour plus de détails sur cette configuration, consultez le [Guide Administrateur](/fr/admin-guide/platform-governance/).

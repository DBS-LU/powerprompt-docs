## 1. Un écosystème multi-navigateurs

Power Prompt met à disposition des extensions natives pour l'ensemble des navigateurs majeurs du marché :
* **Google Chrome**
* **Microsoft Edge**
* **Mozilla Firefox**
* **Apple Safari**
* **Opera**
* **Brave**
* **Vivaldi**

---

### Comment installer votre extension

L'installation s'effectue en quelques secondes depuis votre compte Power Prompt :
1. Connectez-vous à la plateforme web Power Prompt.
2. Rendez-vous dans votre **Espace personnel** (*Personal Space*) en cliquant sur votre profil ou sur la roue crantée en bas à gauche de la barre latérale.
3. Basculez sur l'onglet **Extensions**.
4. Repérez la carte correspondant à votre navigateur habituel.
5. Cliquez sur le bouton **Installer** (*Install*) pour ajouter l'extension directement à votre navigateur.
6. Épinglez l'icône Power Prompt dans la barre d'outils de votre navigateur pour un accès permanent en un clic.

## 2. Anatomie de l'extension Power Prompt

L'extension regroupe l'essentiel des fonctionnalités de la bibliothèque dans une interface compacte et fluide :

### Barre d'outils et recherche rapide

* **Recherche instantanée (`Search prompts`)** : filtre en temps réel l'ensemble des prompts par mots-clés dans les titres et descriptions.
* **Filtres par statut** :
  * **All** : affiche tous les prompts certifiés accessibles.
  * **Favorites** : isole les prompts marqués d'une étoile pour un accès immédiat aux routines quotidiennes.
  * **Drafts** : affiche vos brouillons personnels en cours de rédaction.
  * **Category** : menu déroulant permettant de filtrer par dossier thématique (ex: *Productivity*, *Support*, *Marketing*).
* **Compteurs et tri** : affiche le nombre de prompts disponibles (ex: *12 prompts*), le nombre de favoris et le tri sélectionné (*Sort: Recent*).

---

### Fiches de prompts et actions directes

Chaque fiche de prompt présente les repères clés :
* **Badge de catégorie** : dossier métier d'appartenance (ex: `📁 ⚡ Productivity`).
* **Étoile de favori** : permet d'ajouter ou de retirer le prompt de vos favoris en un clic.
* **Titre et description** : identification immédiate de la finalité du prompt (ex: *Productivity coach and time management expert*).
* **Bouton Copier** : place le prompt finalisé dans votre presse-papier.
* **Bouton Éditer (icône Crayon)** : ouvre directement le prompt dans l'éditeur de l'application web pour apporter des modifications ou publier une nouvelle version.

---

### Bouton de création rapide (`+`)

Le bouton rond bleu flottant `+` situé en bas à droite permet de rédiger un nouveau prompt immédiatement depuis l'extension, sans devoir basculer sur l'application complète.

---

### Contrôles de navigation inférieurs

* **Sélecteur d'espace de travail (`All workspaces`)** : permet de basculer instantanément d'un espace de travail à un autre pour charger les prompts de l'équipe concernée.
* **Lien d'ouverture de l'application** : ouvre l'interface complète de Power Prompt dans un nouvel onglet.
* **Déconnexion** : ferme la session sécurisée sur le poste de travail.

---

## 3. Utilisation au quotidien

### Injection dans vos outils web

L'extension s'intègre naturellement avec toutes vos interfaces de travail :
1. Placez votre curseur dans le champ de saisie de votre outil web (ex: ChatGPT, Claude, Microsoft Copilot).
2. Ouvrez l'extension Power Prompt via son icône ou son raccourci clavier.
3. Sélectionnez le prompt adapté à votre tâche.
4. Si le prompt contient des variables dynamiques `{{variable}}`, saisissez les valeurs contextuelles dans la fenêtre d'exécution.
5. Copiez ou insérez le prompt prêt à l'emploi.
